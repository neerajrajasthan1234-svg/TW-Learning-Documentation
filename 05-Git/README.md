# Git – Version Control

## 1. Introduction

Git is a distributed version control system used to track changes in source code and files.

## 2. Basic Git Commands

| Command | Purpose |
|---|---|
| `git --version` | Check Git version |
| `git init` | Initialize a repository |
| `git status` | Check repository status |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Save staged changes |
| `git log` | Display commit history |
| `git log --oneline` | Display short commit history |

## 3. Git Workflow

1. Create or modify files.
2. Check changes using `git status`.
3. Stage changes using `git add`.
4. Commit changes using `git commit`.
5. View history using `git log`.

## 4. Conclusion

Git helps maintain project history and manage changes efficiently.
