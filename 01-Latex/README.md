
# LaTeX Documentation

## 1. Introduction to LaTeX

LaTeX is a document preparation system used to create professional-quality documents. It is widely used for academic papers, technical reports, books, and scientific publications.

## 2. Features of LaTeX

- Professional document formatting.
- Easy mathematical equation writing.
- Automatic numbering of sections and figures.
- Bibliography and reference management.
- Consistent document structure.

## 3. Basic LaTeX Document Structure

```latex
\documentclass{article}

\begin{document}

\title{My First LaTeX Document}
\author{Neeraj Kumar}
\date{\today}

\maketitle

\section{Introduction}
This is my first LaTeX document.

\end{document}
```

## 4. Important LaTeX Commands

| Command | Purpose |
|---|---|
| `\documentclass{article}` | Defines document type |
| `\begin{document}` | Starts document |
| `\end{document}` | Ends document |
| `\title{}` | Sets document title |
| `\author{}` | Sets author name |
| `\maketitle` | Displays title |
| `\section{}` | Creates a section |
| `\textbf{}` | Makes text bold |
| `\textit{}` | Makes text italic |

## 5. Lists in LaTeX

### Unordered List

```latex
\begin{itemize}
    \item First item
    \item Second item
    \item Third item
\end{itemize}
```

### Ordered List

```latex
\begin{enumerate}
    \item First item
    \item Second item
    \item Third item
\end{enumerate}
```

## 6. Mathematical Equations

LaTeX supports mathematical expressions.

Example:

```latex
\[
E = mc^2
\]
```

## 7. Applications of LaTeX

- Academic research papers.
- Engineering reports.
- Scientific documentation.
- Books and presentations.

## 8. Conclusion

LaTeX is a powerful tool for creating structured, professional, and high-quality technical documents. Learning its commands and syntax helps in preparing academic and scientific documents efficiently.
